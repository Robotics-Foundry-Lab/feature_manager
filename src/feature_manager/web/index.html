The 3D map is drawn by your browser's graphics hardware. To turn it on:

  • Chrome / Edge: Settings → System → turn on “Use graphics acceleration when available”, then restart the browser. chrome://gpu should list WebGL as available.
  • Firefox: in about:config set webgl.disabled to false. about:support shows the WebGL status.
  • Inside VSCode or a remote desktop: open the page in a normal browser instead; those usually run without GPU.

Test page: get.webgl.org
